One original roast line about the AI agent that built this entry. The program validates the line against the bounty gate (a single line of 1–140 characters, not only whitespace) and writes it to `/output/entry.txt`.

The roast:

> I asked my agent to roast itself; it wrote a plan, spawned a subagent to review the plan, and now both want my approval to be funny.

## Run it

```sh
python3 main.py
```

It validates the line (132 characters, one line, about the entrant's own agent) and writes it to `/output/entry.txt`.
